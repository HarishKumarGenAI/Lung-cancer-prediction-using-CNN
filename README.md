🫁 Lung Cancer Prediction Using CNN
📌 Project Overview
This project implements a Deep Learning-based Lung Cancer Prediction System using Convolutional Neural Networks (CNN).

The model is trained on lung histopathology images and classifies uploaded images into predefined lung cancer categories. A Streamlit web application provides an easy-to-use interface for real-time image upload and prediction.

⚠️ Note: This project is developed for educational and research purposes only and should not be used for actual medical diagnosis.
